## Guidance and illumination dependency

R-27R requires an external compatible radar illumination source for terminal SARH guidance. The aircraft's radar/weapon control system and the missile are separate state owners:
- carrier radar/weapon system establishes and maintains the compatible illumination/target support state;
- RF environment carries the physical illumination and target-return interactions;
- missile seeker observes the return and estimates angular error/track quality;
- missile guidance law uses that measurement plus its own inertial state;
- interruption, masking, radar fault, target-return loss or seeker fault degrades or terminates the valid guidance state according to evidence-backed logic.

Do not give R-27R a self-contained active-radar terminal mode. Do not silently substitute an R-27EA/active seeker. The exact midcourse correction behavior and carrier radar/launch software interfaces need product-specific documentation.

## Flight and vehicle requirements

A credible runtime needs exact missile-body geometry, mass distribution, motor thrust-time/propellant consumption, aerodynamic coefficient tables, control-surface positions, actuator behavior, guidance loop dynamics, fuze and warhead. These are not supplied in sufficient detail by the current public sources.

Until sourced:
- store dimensions/mass as unknown;
- use test-only synthetic curves for solver verification;
- expose the trajectory model tier;
- never claim verified R-27R kinematics/range;
- keep any WEG maximum-range or engagement-envelope statements as reference annotations only.

## Platform fit caution

The DCS MiG-29 manual is a simulator reference and describes a standard configuration with R-27R and R-73. That is useful for a simulated starting scenario, not independent proof of all product 9.13 production/operator clearances. Keep the store enabled only in a named project fit whose evidence records this limitation.

## Required tests

- Enforce SARH external illumination dependency.
- Reject ARH and R-27T IR-seeker fields.
- Illumination present/lost/intermittent; radar shutdown; target return obscured or lost.
- Seeker angle measurement uncertainty, scan/revisit/update age and track maintenance.
- Multiple emitters/returns and ambiguous associations where supported.
- Track loss/coast/reacquisition and deterministic replay.
- Synthetic-only motor/aero validation until real variant data is sourced.
