# M61A1 Vulcan — F-16C gun installation evidence profile

**Stable profile ID:** weapon.m61a1.vulcan  
**Platform association:** F-16C Block 50 internal gun.  
**Evidence status:** USAF National Museum establishes gun family and cyclic rate; USAF aircraft fact sheet establishes F-16 armament and a 500-round figure. Public sources disagree on exact installed ammunition capacity (500 vs 511); the project must preserve that discrepancy until exact F-16C Block 50 documentation settles it.  
**Variant boundary:** M61A1 is not M61A2. Do not transfer M61A2 mass/installation details to the F-16C Block 50.

## Gun and feed model requirements

Do not represent the gun as a hits-per-second generator. The gun subsystem should track:
- selected ammunition belt/mix as an explicit platform load configuration;
- rounds in feed path, remaining inventory and feed events;
- spin-up / firing enable state and barrel-group rotation state at the declared fidelity;
- trigger command, firing authorization and inhibit/interlock conditions;
- cyclic rate and burst timing, with projectile emission at actual simulation time;
- projectile type, mass/shape/initial velocity data and source status;
- recoil/force and moment at the installed position, including influence on aircraft motion;
- dispersion/shot pattern and gun harmonics only to the level supported by evidence;
- heat, wear, feed fault, stoppage and damage only when a defensible model exists.

The aircraft package owns gun bay installation, feed path, muzzle location, cockpit trigger and ammunition count/indication. The shared ballistics engine owns projectile flight; armour/collision/damage owns the result of impact.

## Required tests

- Round inventory and feed accounting; no firing after empty or feed failure.
- Burst cadence independent of render rate; no extra rounds on render interpolation.
- Recoil force/moment applied at correct installation location.
- Deterministic projectile stream and dispersion with scoped random seed.
- Projectile-to-target physical collision and armour/damage handoff.
- Gun jam, power loss, feed fault and recovery remain separate fault states.
- 500 vs 511 capacity is a resolved variant-configuration choice, not hard-coded global constant.
