# 07 — Propagation and Environment

## Purpose
Describe how radar energy travels between antenna and target and how the environment modifies outgoing and returning signals.

## Categories
- **Free-space propagation:** geometric spreading and baseline path loss.
- **Atmospheric absorption:** frequency-dependent gaseous attenuation and modeled atmospheric losses.
- **Rain and precipitation:** attenuation and scattering where relevant.
- **Humidity and refractivity:** propagation changes and effective-range behavior.
- **Tropospheric effects:** refraction, ducting, and anomalous propagation at the selected fidelity level.
- **Terrain masking:** line of sight, elevation data, ridgelines, valleys, and Earth curvature where relevant.
- **Vegetation and structures:** occlusion and simplified attenuation from forests, buildings, and obstacles.
- **Sea and ground environment:** surface reflection, roughness, grazing angle, and clutter inputs.
- **Multipath:** direct/reflected paths, phase differences, fading, and geometry-dependent interference.
- **Uncertainty:** model resolution, environmental-data quality, and uncertainty reporting.

## Fidelity
Use fast line-of-sight/propagation approximations for broad simulation and more detailed calculations for selected lab cases. State each model's limits.

Describes the path through the environment. Target scattering is folder 08; receiver noise is folder 09.
