# 03 — RF Hardware

## Purpose
Describe the physical electronic equipment that generates, routes, amplifies, receives, and supports radar RF signals.

## Categories
- **Exciter and reference source:** frequency generation, phase reference, stability, synchronization, and agility.
- **Waveform-generation hardware:** timing control, modulation capability, pulse shaping, and hardware limits.
- **Transmit chain:** power amplifiers, transmit modules, peak/average power, duty cycle, and output losses.
- **Power distribution:** bus voltage, conversion efficiency, transient demand, power quality, and load shedding.
- **Transmit/receive switching:** duplexing, blanking, isolation, leakage, receiver protection, and recovery time.
- **RF distribution:** waveguides, coaxial paths, switches, combiners, splitters, and insertion loss.
- **Thermal management:** cooling capacity, heat generation, temperature limits, warm-up, and duty-cycle restrictions.
- **Calibration and built-in test:** reference paths, test signals, alignment, health checks, and calibration drift.
- **Hardware health:** component wear, module faults, connector/feed damage, and degraded states.

## Interactions
Electrical power and cooling constrain output and duty cycle. Localized hardware faults should affect the relevant channel or capability where appropriate.

## Boundary
Physical RF/support hardware only. Antenna patterns belong in folder 05; sample processing belongs in later folders.
