# Spall and secondary fragment effects

**Owner:** physics/armour/spall. Generate bounded secondary fragment/energy distributions from supported penetration/impact models. Platform packages supply internal layout, protected volumes, components and crew positions; this folder does not decide what equipment/people exist inside a vehicle.

Output fragment count/distribution, direction, energy/range and uncertainty at declared fidelity. Keep simplified stochastic spall visibly distinct from validated fragment hydrodynamics. Seed by stable impact/entity identity so replay is repeatable.

Validate fragment/energy bounds, angle/material/thickness trends, protected-volume intersection and downstream damage routing.
