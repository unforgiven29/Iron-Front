# Seeker component definitions

Own seeker equipment/configuration data: type/band, aperture/FOV, scan/search pattern, receiver/detector limits, acquisition gates, tracking limits, update rate, noise/uncertainty, countermeasure susceptibilities, cooling/power and supported modes. Sensor owner executes the physical detection chain.

Define search, candidate, acquisition, track, coast, lost, reacquire and reject states. Seeker receives observations, not hidden target truth. A cue is not an automatic lock. Validate FOV edges, gimbal/scan limits, clutter/background, signal-to-noise, false alarms, missed updates, countermeasure interaction, resource loss and track uncertainty.
