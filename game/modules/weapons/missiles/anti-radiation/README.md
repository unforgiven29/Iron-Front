# Anti-radiation missile variants

Own exact anti-radiation seeker, frequency/scan/receiver limitations, emitter association policy, memory/last-known-source logic, navigation/guidance, motor, fuze/warhead and launcher fit.

The seeker observes actual RF emissions through a sensor contract. It never accesses private radar objects, internal mode flags or campaign truth. A silent/relocated/destroyed emitter may create memory/coasting behavior only if the exact seeker supports it; it does not guarantee an impact on the emitter's current position.

Validate emission availability, changing source frequency/beam, emitter shutdown, memory accuracy/age, multiple sources, decoys, navigation uncertainty, terminal guidance and warhead effects.
