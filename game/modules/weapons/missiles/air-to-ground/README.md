# Air-to-ground missile variants

Own exact AGM configuration: body, mass/drag, motor, seeker/guidance architecture, target/designation dependency, fuze/warhead, launch envelope, launcher compatibility and provenance.

Supported modes may include inertial, command, laser, imaging, millimeter-wave or other seeker types, but only if the selected product/equipment baseline supports them. Designation, lock and midcourse updates enter through sensor/data-link contracts and carry age/uncertainty. Do not supply campaign target truth.

Validate target designation handoff, moving/static target assumptions, obscurant/weather limits, seeker reacquisition, guidance loss, launch envelope, safe separation, fuze and damage outcomes.
