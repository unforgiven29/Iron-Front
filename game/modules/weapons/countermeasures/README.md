# Countermeasures and expendables

Own chaff/flare/decoy product definitions, physical/signature parameters, dispenser compatibility, inventory, release timing, safe separation and command interfaces. Sensor/seeker and RF/optical/thermal physics determine whether an effect changes a received signal.

A release is an event, not guaranteed defeat. Chaff must enter radar signal/processing environment; flare affects infrared scene/signature; active decoys require their own emissions/power/state. No universal success multiplier or guaranteed missile miss. Platform owns dispenser location, power, programming and cockpit control.

Validate inventory, timing, launch safety, wind/trajectory, signature/path response, seeker processing, multiple release interference and damage/failure.
