# Active RF decoys and repeater emitters

**Owner:** decoy product/deployment. RF generation, propagation and reception use canonical RF/radar owners; seeker association uses sensors/weapon-seeker.

Active RF decoys create their own emission or retransmission state. They are distinct from passive chaff and from noise jamming generated by an aircraft's installed ECM system.

## Profile axes

Describe active source type at an abstract system level; supported frequency/band and waveform compatibility where known; effective radiated output or an abstract sourced emission envelope; antenna pattern/orientation; timing/duty cycle; response/latency for repeaters; power source/energy endurance; activation delay and modes; physical deployment/platform location; movement/drag; thermal state; and source/provenance.

Do not invent specific waveform details or classified capabilities. A profile can declare an unavailable/unknown parameter.

## Runtime behavior

An active decoy has a power/health/mode state and a moving position/orientation. Its emission enters the RF environment through physics/radar; receivers observe only propagated signals. Its presence may produce a candidate return/emitter, interference or no useful observation depending on receiver and geometry.

## Tests

Test activation, power depletion, antenna orientation, emission intermittency, movement/separation, path loss, receiver band compatibility, multiple-source association, damage and deterministic replay. Do not treat an active decoy as a guaranteed spoof.
