# Torpedo variants

Own exact torpedo body/propulsion, water-motion control, speed/depth limits, seeker (acoustic/wire/other when fitted), guidance, arming/fuze, warhead, launcher interface and provenance. Ship/submarine modules own tubes, launch doors, handling and fire-control; shared physical water/hydrodynamic service owns the supported medium interaction.

Torpedo guidance consumes acoustic/wire/command observations with noise, range, bearing, ambiguity and latency. It cannot read a submarine/ship entity's exact location. Propulsion, steering, depth control, wake/thermal/acoustic signatures and counter-countermeasure behavior are capability-specific.

Validate tube ejection/water entry, depth hold, turning/propulsion, seeker acquisition, wire cut/loss, acoustic clutter/decoys, arming and impact/damage.
