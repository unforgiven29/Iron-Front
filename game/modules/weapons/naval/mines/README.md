# Naval mine variants

Own mine product definition, deployment/handling interface, anchor/drift state where applicable, arming delay, activation/sensing mechanism, target criteria, fuzing, effect and provenance. Ship/submarine modules own stowage, deployment equipment and orders; world/water supply depth/current data; damage service resolves effects.

A mine must not detonate because a campaign unit crossed an invisible trigger sphere unless the selected sensing model supports that observable. Distinguish safe, deployed, settling, armed, triggered, dud, neutralized and expired states.

Validate deployment geometry, water depth/current, arming delay, influence sensing assumptions, false trigger, neutralization and save/restore.
