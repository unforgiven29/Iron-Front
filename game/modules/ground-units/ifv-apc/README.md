# IFV and APC platform modules

Each package represents an exact IFV/APC variant with hull/mass/mobility, armor, crew and passenger capacity, weapon stations, sights, communications, fuel/power/hydraulic topology, dismount points, doors/ramps, damage zones and provenance.

IFV and APC are not interchangeable feature bundles. IFV may carry a more capable turret/fire-control fit; APC emphasizes protected troop transport; exact equipment is variant data. Passenger seats/stowage constrain capacity and dismount behavior. Dismounted infantry become independent entities through a typed dismount event and receive identity/equipment/load state; they do not appear as an untracked visual effect.

Use shared tracked/wheeled mobility, armor, ballistics, weapons, crew, sensors and damage services. Validate mobility, troop capacity, embark/disembark, door/ramp damage, passenger/crew casualties, station compatibility, weapon stabilization and transport/logistics handoff.
