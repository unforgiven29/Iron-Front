# Ground-based air-defence platform modules

Own exact launcher/radar/EO fit, antenna/aperture installation, missile/gun stations, crew, deployment state, power/cooling, hydraulics, communications, reload and damage topology. A site may be composed from separate radar, command, launcher and support entities; do not assume one vehicle owns all functions.

Detection/track/identification/engagement use fitted sensors and command links. Local radar detects through the shared signal chain; ESM/RWR may observe emissions independently; remote reports arrive over communications with latency. Engagement logic uses uncertain reports, launcher readiness, missile/weapon limits and authorization. Never query campaign enemy aircraft lists.

Validate radar blackout/emission control, terrain masking, report latency, launcher link loss, power/cooling/hydraulic failure, reload/ammo, weapon compatibility, crew and damage, and no hidden-truth engagement.
