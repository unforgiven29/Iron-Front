# MiG-29 Product 9.13 — Technical Reference Library

Requested project label: **MiG-29A 9.13**. Internal technical identity must remain **product 9.13**. Naming varies across sources: 9.12 is commonly called Fulcrum-A; 9.13 is the enlarged-spine Fulcrum-C; 9.13S is a later improved version. Do not silently merge them.

Read [variant baseline](variant-baseline.md), [flight model](flight-model/README.md), [radar](radar/README.md), [RWR](rwr/README.md), [other sensors/EW](sensors/README.md), [propulsion](propulsion/README.md), [avionics](avionics/README.md), [cockpit](cockpit/README.md), [airframe systems](airframe-systems/README.md), [weapons/stores](weapons-stores/README.md), [references](references/README.md) and [images](images/README.md).

The available DCS manual models 9-12 as MiG-29A and 9-13 as MiG-29S; it is useful for general system descriptions but is not an exact plain-9.13 operating manual. Public evidence also differs on Beryoza RWR designation (L006LM vs SPO-15LM). That uncertainty is documented rather than guessed. Linked manuals/images are not redistributed. Local SVGs are original conceptual diagrams.
