# MiG-29 Product 9.13 — N019 / RLPK-29 Radar

Working baseline: N019 "Rubin" within the RLPK-29 fire-control complex. This is a mechanically scanned pulse-Doppler radar, not AESA. Keep antenna, transmitter/receiver, signal processing, weapon-control computer and cockpit indication distinct.

Model finite azimuth/elevation scan, dwell/revisit, search/acquisition/track, high/medium PRF behavior where supported, look-down clutter, Doppler/aspect limitations, range/velocity ambiguity, measurement uncertainty and missile-support emissions. Publish real time-stamped RF emissions to the shared RF environment.

Do not import N019M/Topaz, N010 Zhuk, TWS2 or R-77 integration from later 9.13S/SE/M/SMT variants. Do not use a single public detection-range figure as a guaranteed range. Exact waveform, power, sensitivity and processing values require provenance.

Source: [Eagle Dynamics MiG-29 Flight Manual](https://www.digitalcombatsimulator.com/upload/iblock/463/DCS%20MIG-29%20Flight%20Manual%20EN.pdf) (simulator documentation; 9-13 is represented as MiG-29S); [AirWingMedia variant overview](https://airwingmedia.com/downloads/mikoyan-mig-29-fulcrum-pdf-ebook-flight-manuals/).
