# MiG-29 Product 9.13 — Variant Baseline

Use stable ID `mig29-9-13-soviet-baseline-v1`. Keep the requested folder name MiG-29A, but preserve product number 9.13 in data and manifests.

| Item | Working baseline | Confidence / caveat |
|---|---|---|
| Airframe | Single-seat product 9.13 | High |
| Distinguishing feature | Enlarged dorsal spine / additional internal fuel | Secondary-source evidence; verify primary source |
| Engines | Two RD-33 | High |
| Radar | N019 / RLPK-29 family | Exact 9.13 hardware/software needs matching source |
| Optical system | OEPS-29 / KOLS family; Shchel-3UM helmet sight | Confirm exact 9.13 revision |
| RWR | Beryoza family | Exact L006LM / SPO-15LM nomenclature and revision unresolved |
| ECM | L-203BE Gardenyia-1 associated with 9.13 | Secondary-source evidence; confirm fit |
| Weapons | 9.13-specific compatibility list | Do not inherit all 9.13S / export / SMT weapons |

The Eagle Dynamics manual explicitly represents MiG-29A as 9-12 and MiG-29S as 9-13. Its 9-13S-specific features (for example TWS2/R-77) must not be assigned to plain 9.13 without evidence. 9.13B, 9.13S, 9.13SE, SMT and MiG-29M are separate configurations.

Sources: [Eagle Dynamics manual](https://www.digitalcombatsimulator.com/upload/iblock/463/DCS%20MIG-29%20Flight%20Manual%20EN.pdf); [AirWingMedia variant overview](https://airwingmedia.com/downloads/mikoyan-mig-29-fulcrum-pdf-ebook-flight-manuals/).
