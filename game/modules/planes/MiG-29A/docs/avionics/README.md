# MiG-29 Product 9.13 — Avionics and Navigation

Document RLPK-29/N019 radar, OEPrNK-29, OEPS-29/KOLS, Shchel-3UM helmet sight, SAU-29 stability augmentation, navigation/air-data, IFF, radios, SEI-31 indication, warning panels, weapon control and Beryoza/Gardenyia integration where confirmed.

Preserve Russian equipment names, transliteration and English translation. Radar and optical/laser measurements remain separate. Helmet sight provides cueing, not a perfect target track. All cockpit indications derive from actual subsystem state and power. Do not import MiG-29S 9-13 TWS2/R-77 behavior into plain 9.13 without evidence.

Source: [Eagle Dynamics MiG-29 Flight Manual](https://www.digitalcombatsimulator.com/upload/iblock/463/DCS%20MIG-29%20Flight%20Manual%20EN.pdf) (simulation reference with 9-12 / 9-13S caveat).
