# MiG-29 Product 9.13 — Weapons and External Stores

Define exact hardpoints, pylons, compatibility, store mass/CG/inertia, drag, release logic, electrical/data interfaces and safe-separation constraints. Potential early-fit stores include R-27 family, R-73, R-60, gun, bombs/unguided rockets and external fuel tanks where confirmed by operator/date.

Do not import R-77 compatibility, multi-target engagement or later weapon clearances from 9.13S/SE/SMT/M variants. Store release changes mass, CG, inertia, drag and inventory. ECM and dispenser fit must be separately configured.

Sources: [Eagle Dynamics MiG-29 manual](https://www.digitalcombatsimulator.com/upload/iblock/463/DCS%20MIG-29%20Flight%20Manual%20EN.pdf); [AirWingMedia variant overview](https://airwingmedia.com/downloads/mikoyan-mig-29-fulcrum-pdf-ebook-flight-manuals/).
