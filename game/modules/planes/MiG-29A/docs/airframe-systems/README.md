# MiG-29 Product 9.13 — Airframe and Aircraft Systems

Document integral wing/body and LERX geometry, twin tails, engine nacelles/inlets, control surfaces, hydraulic actuation, stability augmentation, enlarged-spine fuel tank, fuel feed/transfer, electrical generation/buses, environmental control, landing gear, brakes, airbrakes, brake parachute, canopy/ejection, sensor apertures and damage routing.

Keep left/right engines independent. Fuel burn/transfer changes mass properties. Hydraulic/electrical faults degrade only connected functions. The 9.13 spine is a structural and fuel-volume change, not a cosmetic mesh. Do not assume redundancy or emergency modes without a matching source.

Sources: [Eagle Dynamics MiG-29 manual](https://www.digitalcombatsimulator.com/upload/iblock/463/DCS%20MIG-29%20Flight%20Manual%20EN.pdf); [AirWingMedia variant overview](https://airwingmedia.com/downloads/mikoyan-mig-29-fulcrum-pdf-ebook-flight-manuals/); [NPS archive report](https://calhoun.nps.edu/server/api/core/bitstreams/eeeed8aa-eee4-4ca5-abee-b74c2891194b/content).
