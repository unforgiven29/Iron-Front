# MiG-29 Product 9.13 — Twin RD-33 Engines

Use two independent RD-33 turbofan instances. Model independent spool inertia, fuel flow, start/stop, afterburner, temperature/oil state, surge/stall, flameout, fire, damage, relight, accessory loads and exhaust signature. Single-engine failure must produce asymmetric thrust and drag.

The 9.13 enlarged spine changes internal fuel volume and mass distribution. Represent tank location, feed/transfer and CG effects explicitly; do not implement a simple range multiplier. Shared propulsion owns engine-family physics; this aircraft folder owns fit and installation.

Sources: [Eagle Dynamics MiG-29 manual](https://www.digitalcombatsimulator.com/upload/iblock/463/DCS%20MIG-29%20Flight%20Manual%20EN.pdf) (includes 9-12/9-13 comparison); [NPS archive report](https://calhoun.nps.edu/server/api/core/bitstreams/eeeed8aa-eee4-4ca5-abee-b74c2891194b/content).
