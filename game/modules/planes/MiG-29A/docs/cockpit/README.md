# MiG-29 Product 9.13 — Cockpit Reference

The early cockpit is predominantly analog with dedicated indicators, warning lamps, radar/weapon controls and HUD. Later modernized/export cockpits differ; do not create a glass cockpit without variant evidence.

For every control record Cyrillic label, transliteration, translation, panel location, control type/detents, owning subsystem, power/preconditions, feedback/failure state and source figure/page. Prioritize flight/engine/fuel/hydraulic/electrical instruments, HUD, radar controls, RWR panel/audio, OEPS/helmet sight, SAU-29, weapons, radios/navigation and emergency controls.

Visual sources: [Eagle Dynamics MiG-29 manual](https://www.digitalcombatsimulator.com/upload/iblock/463/DCS%20MIG-29%20Flight%20Manual%20EN.pdf) (simplified simulator cockpit); [AVSIM cockpit instrument layout](https://avsimrus.com/forum/topic/35038-%D1%85%D0%B0%D1%80%D0%B0%D0%BA%D1%82%D0%B5%D1%80%D0%B8%D1%81%D1%82%D0%B8%D0%BA%D0%B0-%D0%BF%D1%80%D0%B8%D0%B1%D0%BE%D1%80%D0%BE%D0%B2-%D0%BA%D0%B0%D0%B1%D0%B8%D0%BD%D1%8B-%D0%BC%D0%B8%D0%B3-29/) (community source; verify variant); [DefenceTalk cockpit photo](https://www.defencetalk.com/military/photos/mig-29-fulcrum.461/full?d=1514049804) (visual only).
