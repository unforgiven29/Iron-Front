# MiG-29 Product 9.13 — Optical Sensors and Electronic Warfare

Baseline equipment families to investigate:
- OEPS-29 / KOLS electro-optical sighting system (passive IR detection and active laser ranging are separate functions).
- Shchel-3UM helmet-mounted sight for off-boresight cueing; it is not a magical target track.
- Beryoza-family RWR (see [RWR brief](../rwr/README.md)).
- L-203BE Gardenyia-1 ECM is associated with the enlarged 9.13 spine in secondary references; exact installation/operational fit must be verified.

IRST reports angular measurements with uncertainty and is affected by aspect, atmosphere and background. Laser ranging is an active event with line-of-sight limitations. Helmet cueing transforms pilot head line-of-sight within actual gimbal limits. ECM consumes resources and emits RF, potentially revealing the aircraft. Do not import later MiG-29S/SE/SMT sensor upgrades.

Sources: [Eagle Dynamics MiG-29 manual](https://www.digitalcombatsimulator.com/upload/iblock/463/DCS%20MIG-29%20Flight%20Manual%20EN.pdf); [AirWingMedia variants](https://airwingmedia.com/downloads/mikoyan-mig-29-fulcrum-pdf-ebook-flight-manuals/); [NPS archive report](https://calhoun.nps.edu/server/api/core/bitstreams/eeeed8aa-eee4-4ca5-abee-b74c2891194b/content).
