# F-16C Block 50 — Cockpit Reference

The F-16 cockpit has a side-stick, left throttle, HUD, ICP/UFC, MFDs, standby/analog instruments and dedicated warning/control panels. Layout and display hardware vary by operator and modernization.

For each switch/instrument record physical location, label, control type, detents/range, owning subsystem, power source, preconditions/interlocks, feedback, failure behavior and source page/figure. Startup is a state machine with power, fuel, hydraulic, JFS and engine prerequisites—not one button.

Visual references: [USAF educational cockpit overview PDF](https://www.afjag.af.mil/Portals/77/documents/AFD-081204-037.pdf) (broad zones, not Block 50 wiring); [Falcon Lounge Block 50/52 cockpit layout](https://learning.falcon-lounge.com/course/view.php?id=3) (verify provenance/revision); [Falcon BMS Flight Manual 4.38](https://cdn.falcon-bms.com/docs/4.38/TO%201F-16CMAM-1%20BMS.pdf).
