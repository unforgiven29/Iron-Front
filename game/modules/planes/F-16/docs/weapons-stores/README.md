# F-16C Block 50 — Weapons and External Stores

Block 50 is strongly associated with Wild Weasel / SEAD and AGM-88 HARM, but HTS, ECM pods and weapons are explicit mission-fit choices. Define each station's compatibility, mass, CG/inertia, geometry, drag, attachment transform, electrical/data interface and release logic.

Potential stores depend on operator/date: AIM-9/AIM-120, AGM-88 and HTS, ALQ-131/184, external tanks, bombs, rockets and targeting pods. Do not infer compatibility from a 3D attachment point. Release/jettison changes mass, CG, inertia, drag and inventory. Do not combine later clearances with an earlier OFP.

Sources: [DCS Block 50 announcement](https://www.digitalcombatsimulator.com/es/news/2019-02-15_Beta/); [Falcon BMS avionics manual](https://cdn.falcon-bms.com/docs/4.37/TO%201F-16CMAM-34-1-1%20BMS.pdf).
