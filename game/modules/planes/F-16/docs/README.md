# F-16C Block 50 — Technical Reference Library

Project baseline: single-seat USAF-style F-16C Block 50, CCIP-era configuration; F110-GE-129; AN/APG-68(V)5; AN/ALR-56M. This is a selected simulation baseline, not a claim that every Block 50 has the same equipment.

Claude: read [variant-baseline](variant-baseline.md), then the [flight model](flight-model/README.md), [radar](radar/README.md), [RWR](rwr/README.md), [other sensors/EW](sensors/README.md), [propulsion](propulsion/README.md), [avionics](avionics/README.md), [cockpit](cockpit/README.md), [airframe systems](airframe-systems/README.md), [weapons/stores](weapons-stores/README.md), [references](references/README.md) and [images](images/README.md).

Rules: never mix Block 50 with Block 52 engine, APG-68(V)9, APG-83 AESA, IVEWS or later software without an explicit separate configuration. Mark unsourced values unknown/estimated/synthetic. External manuals and images are linked, not redistributed. Local SVGs are original conceptual diagrams, not manufacturer drawings.
