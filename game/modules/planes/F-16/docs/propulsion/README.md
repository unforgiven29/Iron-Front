# F-16C Block 50 — F110-GE-129

Selected fit: one GE F110-GE-129 afterburning turbofan. Do not mix with Block 52 F100-PW-229. Shared propulsion owns engine-family physics; the F-16 module supplies installation, control mapping, limits and aircraft interfaces.

Model spool inertia, fuel metering, engine-control modes, variable geometry, afterburner staging, nozzle response, thrust lapse with altitude/Mach, fuel flow, temperature, oil, RPM, start/relight, surge/stall, flameout, fire, damage, accessory loads and thermal/vibration outputs. Engine output feeds rigid-body forces, fuel, electrical/hydraulic resources and IR signature.

Sources: [Falcon BMS Flight Manual 4.38](https://cdn.falcon-bms.com/docs/4.38/TO%201F-16CMAM-1%20BMS.pdf); [DCS Block 50 announcement](https://www.digitalcombatsimulator.com/es/news/2019-02-15_Beta/); [F-16.net variant overview](https://www.f-16.net/f-16_versions_article9.html). Do not derive a complete engine map from a maximum-thrust figure.
