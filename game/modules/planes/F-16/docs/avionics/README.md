# F-16C Block 50 — Avionics and Navigation

Document the selected mission-computer/OFP baseline, INS/GPS/EGI alignment and degraded modes, HUD symbology, MFD pages, SOI/cursor behavior, ICP/UFC, radios, IFF, datalink, stores management, BIT and fault annunciation.

Every page must display actual subsystem output and data age. Controls issue typed commands to owning systems; cockpit code does not directly mutate physics. Link 16/MIDS, JHMCS, color displays, targeting pods, HTS and later weapon clearances are versioned fit choices, not universal assumptions.

Sources: [Falcon BMS avionics manual](https://cdn.falcon-bms.com/docs/4.37/TO%201F-16CMAM-34-1-1%20BMS.pdf); [DCS Block 50 baseline](https://www.digitalcombatsimulator.com/es/news/2019-02-15_Beta/).
