# RWR Validation Work

Store deterministic test scenarios, reference fixtures, tolerance definitions and benchmark reports here. Every test identifies the RWR configuration, emitter configuration, environment, seed, timestep, expected observables, metrics and provenance.

Separate analytic tests, synthetic regression fixtures and comparisons against public measured references. Never present synthetic data as real-world validation. Comparative claims require a repeatable protocol; feature count or display resemblance is not a benchmark.
